# Recorrido de Pixel Store

Guía para grabar una presentación individual en MP4. Muestra el sitio y el código que explica cada comportamiento. Una duración orientativa es de 5 a 7 minutos; no se fija una duración obligatoria en las instrucciones.

1. Presenta el sitio, la navegación y las tecnologías utilizadas.
2. Muestra las tarjetas y sus datos. Selecciona una categoría, combina el filtro con una búsqueda y enseña el estado sin resultados.
3. Agrega videojuegos al carrito, aumenta una cantidad, revisa el total y elimina un producto.
4. Abre la gestión del catálogo. Agrega un videojuego completo, comprueba su tarjeta, filtra su categoría y elimínalo con confirmación.
5. Envía el contacto vacío y muestra los errores. Prueba un email inválido y después datos válidos. Explica que el envío se simula.
6. Reduce la pantalla para mostrar la navegación móvil, las tarjetas y los formularios.
7. Explica en App.jsx el estado, la carga con useEffect, el JSON y las props. Revisa ListaVideojuegos, Producto, GestionCatalogo y FormularioContacto.
8. Muestra las etiquetas semánticas, las clases Bootstrap y las reglas responsivas de styles.css.
9. Ejecuta las pruebas y muestra el README y el historial de commits.

Comprueba que el MP4 tiene voz comprensible, código legible y un recorrido completo. Adjunta el enlace del repositorio y el ZIP.
